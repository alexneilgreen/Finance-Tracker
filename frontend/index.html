Import Transactions

Upload a Truist "individual line items" CSV export. Each row is logged automatically with a best-guess Line Item — re-uploading the same date range won't create duplicates, and rows it can't confidently categorize are left unassigned for you to review below.

Credits to Review

"Credit" rows from an import (Zelle received, reimbursements, etc.) aren't logged as transactions automatically — add each one to a Sinking Fund, or to a budget category (logged as a refund that reduces that category's Spent total), or dismiss it if it doesn't need tracking.
